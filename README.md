# ai-model-galleries

## AI 模特素材库

这是三个自有 AI 模特素材网站的**私有归档仓库**，用于备份网页与素材，以及后续查找、参考和维护。按照模特脸、姿势、服装分目录保存，不是仅收藏网站链接。

### 上传进度与目录

| 目录 | 内容 | GitHub 上传状态 |

| `pose/` | 模特姿势库 | 已完成并逐文件校验：1,439 张原图 + 1,439 张缩略图；2,891 个归档文件，696,948,754 字节，另附 2 个校验文件 |
| `portrait/` | 模特脸库 | 正在分批上传；完成前不视为完整备份 |
| `costume/` | 模特服装库 | 待处理 |

**姿势库图片已经作为真实图片文件放进 GitHub，不是图片地址列表，也不是只有缩略图。** 其他目录以本表的完成状态为准。

### 文件在哪里、如何预览

- 姿势库原始网页与图片：`pose/original/`；离线页面：`pose/offline/index.html`。
- 模特脸库离线入口（上传完成后）：`portrait/index-offline.html`；目录内保留原始页面、图片、脚本、字体与必要快照，具体路径见该目录 README。
- GitHub 仓库用于浏览和下载文件，**没有部署为在线网站**。下载完整目录后，可在电脑中用本地静态 HTTP 服务打开离线入口；不必登录 Google 邮箱。上传和校验在云端完成，不占用你的电脑执行任务。
- `asset-manifest.json`、`expected-files.json`、`github-upload-verification.json` 记录素材清单与校验结果（以各目录实际文件为准）。

### 归档范围

保存可访问网页、公开前端代码、已发现的素材及必要离线适配。未取得网站后台、数据库、私有源代码仓库或未公开构建文件，因此不把公开网页归档表述为后台源码的 100% 复制。动态接口快照仅代表采集时刻，离线页面不提供原站在线写入能力。

素材仅用于仓库所有者授权的备份与参考；第三方字体等仍遵循原有许可。
